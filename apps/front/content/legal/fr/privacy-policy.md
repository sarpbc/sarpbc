## Introduction

Cette Politique de Confidentialité explique comment sarpbc.org collecte, utilise et protège vos informations personnelles lorsque vous utilisez notre site web et nos services. Nous nous engageons à protéger votre vie privée et à assurer la transparence de nos pratiques de données.

## Responsable du Traitement

**Email de Contact:** contact@sarpbc.org

## Données que Nous Collectons

Nous collectons les types d'informations personnelles suivants :

### Informations de Compte

- Adresse e-mail
- Nom d'utilisateur
- Informations de profil que vous choisissez de fournir

### Informations Techniques

- Adresse IP
- Type et version du navigateur
- Données d'utilisation du site web et analyses

## Comment Nous Utilisons Vos Données

- Pour fournir et maintenir nos services
- Pour communiquer avec vous concernant votre compte et nos services
- Pour améliorer notre site web et l'expérience utilisateur
- Pour respecter les obligations légales

## Base Légale du Traitement

Nous traitons vos données personnelles sur la base de :

- Votre consentement pour les communications marketing et les analyses
- L'exécution de nos conditions de service
- Nos intérêts légitimes dans l'exploitation et l'amélioration de nos services

## Partage des Données

Nous pouvons partager vos données avec :

- Les fournisseurs d'analyses (PostHog) pour l'analyse du site web
- Les fournisseurs d'hébergement pour le fonctionnement du site web
- Les forces de l'ordre ou les autorités réglementaires lorsque requis par la loi

## Vos Droits

Sous le RGPD et la loi française sur la protection des données, vous avez le droit de :

- Accéder à vos données personnelles
- Corriger les données inexactes
- Demander la suppression de vos données
- Portabilité des données
- Vous opposer au traitement
- Déposer une plainte auprès de la CNIL (autorité française de protection des données)

## Conservation des Données

Nous conservons vos données personnelles uniquement aussi longtemps que nécessaire aux fins pour lesquelles elles ont été collectées, ou comme requis par la loi. Les données de compte sont généralement conservées pendant la durée de votre compte plus 3 ans pour la conformité légale.

## Nous Contacter

Si vous avez des questions sur cette Politique de Confidentialité ou souhaitez exercer vos droits, veuillez nous contacter à contact@sarpbc.org.
